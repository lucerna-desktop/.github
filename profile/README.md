<h3 align="center">Lucerna</h3>

<p align="center">Um desktop para o Hyprland: o shell em Quickshell e apps em Rust<br>que funcionam sozinhos no terminal ou integrados ao shell.</p>

<br>

| | | |
|---|---|---|
| [**lucerna-shell**](https://github.com/lucerna-desktop/lucerna-shell) | Barra, painéis, launcher, notificações e configurações | em uso |
| [**lucerna-sdk**](https://github.com/lucerna-desktop/lucerna-sdk) | Protocolo e manifesto entre os apps e o shell | em documentação |
| [**lucernad**](https://github.com/lucerna-desktop/lucernad) | A lógica do shell, fora da interface | em documentação |
| [**lucerna-notes**](https://github.com/lucerna-desktop/lucerna-notes) | Notas em Markdown | em documentação |
| [**lucerna-routine**](https://github.com/lucerna-desktop/lucerna-routine) | Tarefas, hábitos e foco | em documentação |
| [**lucerna-phone**](https://github.com/lucerna-desktop/lucerna-phone) | O celular no computador, com o [app Android](https://github.com/lucerna-desktop/lucerna-phone-android) | em documentação |
